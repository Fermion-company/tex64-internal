# test-workspace — 手で触って確かめるための作業フォルダ

アプリからこのフォルダを開いて機能を試す。ビルド生成物（`*.aux` `*.log` `*.pdf` 等）は
`.gitignore` 済みなので、コンパイルして散らかしてよい。

ビルドのルートファイルは `.tex64/settings.json` で `demo-fourier.tex` に設定してある。

## どこから触るか

| 目的 | 開くファイル |
|---|---|
| 図キャンバス（曲線・頂点編集・図の挿入） | `cases/canvas/canvas-figures.tex` |
| 旧形式の図が 1 行に縮むのを見る | `cases/canvas/canvas-legacy-v1.tex` |
| 日本語 + lualatex のまともな文書でビルド・プレビュー | `demo-fourier.tex` |
| 複数ファイル構成・アウトライン・相互参照 | `main.tex`（`sections/` を include） |
| 数式入力（WYSIWYG サジェスト） | `cases/math-input/formulas.tex` |

## フォルダの中身

- `main.tex` + `sections/` + `refs.bib` — `\include` で分割した標準的な文書。アウトライン・
  参照・引用・ファイル横断の挙動を見る。
- `demo-fourier.tex` — 日本語（luatexja）の完成した文書。ビルドとプレビューの見た目確認用。
- `cases/` — 機能ごとの最小ケース置き場。
  - `canvas/` — 図キャンバス。下に詳細。
  - `math-input/` — 数式入力の網羅的な式。
  - `build/` — わざとエラー・警告を出す文書（未定義コマンド、参照切れ、overfull など）。
  - `blocks/` — 数式ブロック抽出の境界ケース。
  - `format/` — 整形（latexindent）の入出力。
  - `outline/` — 見出し・ラベル・引用・TODO の拾い上げ。
  - `search/` `file-tree/` `encoding/` `text/` `viewer/` — 検索、ファイルツリー表示、文字コード、
    プレーンテキスト系拡張子、画像ビューアの対象形式。
  - `ai/` — Axiom の差分プレビュー用文書とアイコン一覧。
- `figures/` `assets/` — 画像・PDF・データファイル（hover プレビューや取り込みの対象）。
- `notes/` — 整形前後の比較用メモ。
- `sample/` `e2e-paper-test/` — 「ワークスペースの中の別ワークスペース」（それぞれ `.tex64/` を持つ）。
  ネストしたプロジェクトの扱いや、編集前後の比較（`sample/main.tex` と `main_updated.tex`）用。
  2026-08-14 時点でどの自動テストからも参照されていない。

## 図キャンバス（`cases/canvas/`）

`canvas-figures.tex` には編集可能な図が 3 つ入っている。図の行（`%%` の行でも `\draw` の行でも
よい）にカーソルを置くと「図キャンバスで編集」が出る。閉じるときに「TikZ コードを更新」で
その場に書き戻る。

試す順番:

1. 曲線を **1 回クリック**して選ぶ → 頂点□・制御点○・テザーが出て、○ をドラッグすると形が変わる。
2. 曲線の**線の上をドラッグ** → 図形ごと移動（曲がらない）。四隅の丸で伸縮、下の丸で回転。
3. **Delete** → オブジェクトごと削除。
4. **ダブルクリック** → 深い編集。線の上のドラッグで曲げ、線の上のダブルクリックで頂点追加、
   Delete で頂点削除。**Esc** で 1 段戻る（選択は残る）。

`canvas-legacy-v1.tex` は旧形式（`%% tex64-figure+` が 28 行）で保存された図。開いて更新すると
現行形式の `%%` 1 行に置き換わる。行数が減るのをそのまま確認できる。

新しく描いた図を挿入すると、必要な `\usepackage{tikz}` や `\usetikzlibrary{...}` は
プリアンブルに自動で追加される。挿入先はカーソル位置。ただしプリアンブルや別の図・数式環境の
中にはカーソルがあっても入れず、その環境の直後に落として着地点を数秒光らせる。

図データの `%%` 1 行はエディタ上では「▤ 図データ」のチップに畳んで表示される（実体はファイルに
残っているので、そのままコピーしても他の環境で再編集できる）。
