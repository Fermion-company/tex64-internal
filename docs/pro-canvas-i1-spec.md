# Pro Canvas I1: 初見ユーザーが数秒で使い方を理解できるようにする

実測（Playwright, 2026-08-14）: 図キャンバスを初めて開いたとき、空キャンバスには**案内が一切ない**。ツールバーは 8 個のアイコンのみ（ツールチップはホバー必須）。ダブルクリック編集・ホイールでの軸ズーム・`/` の分数化は発見不能。初回コンパイルは約 12 秒。

Claude ⇄ Codex(gpt-5.6-sol) の設計討議で確定した方針（Codex の指摘を採用した点は ★）:

- ★ 全機能を順に説明する **coach-mark ツアーは作らない**。効くのは「空状態」と「対象に結びついたヒント」の 2 つ。
- ★ 空状態の入口は **3 つに絞る**（矩形は推測可能なので外す）。★ **一度消えたら二度と出さない、はやらない**（空に戻ったら再表示する）。
- ★ ツールバーのラベルは**常時表示**（「初回だけラベル」は学習前に消えるので不可）。
- ★ 初回コンパイル中も**キャンバスを覆わない**。近似プレビューを出したまま状態を言葉で説明する。

対象: `web-src/app/pro-canvas/canvas-ui.ts` + `Resources/web/theme.css` + `Resources/web/index.html`。electron/ 不変。

制約（毎回同じ・厳守）: plain tsc / 新規 npm 依存なし / eval・new Function 禁止 / 生成 `Resources/web/**/*.js` は手編集禁止（theme.css・index.html は直接編集可）/ 既存の高密度 1 行スタイルに合わせる / 動的に入れる title・placeholder には `data-no-i18n` / 完了条件は `npx tsc -p web-src/tsconfig.json` 0 エラー + `node --test tests/*.test.cjs tests/*.test.mjs` 全 pass。

## A. ツールバーのラベル常時表示

`.pro-canvas-rail` の各ツールボタンに、アイコンの下へ 10px 程度のラベルを出す。**利用者の目的語**を使う（内部概念名を出さない）:

| tool | ラベル | ツールチップ（従来どおり・ショートカット付き） |
|---|---|---|
| select | 選択 | 選択 (V) |
| pen | ペン | ペン (P) |
| line | 直線 | 直線 (L) |
| rect | 矩形 | 矩形 (R) |
| ellipse | 楕円 | 楕円 (E) |
| node | **数式** | 数式ラベル (T) |
| code | **TikZ** | TikZ コードを直接書く (C) |
| plot | グラフ | グラフ (G) |

- ショートカット文字は**ラベルに混ぜない**（ツールチップのみ）。
- レールは横に広げない。ラベル追加で縦が伸びるのは許容（8 個 × 十数 px）。
- `aria-label` は従来のショートカット付き文字列を維持。

## B. 空状態（空のキャンバスにだけ出る案内）

`.pro-canvas-stage` 内、キャンバス中央に `.pro-canvas-emptystate` を置く。

- 表示条件: `currentObjects().length === 0` かつ `pen` 未進行。**オブジェクトが 0 に戻ったら再び表示する**（削除・undo 後も）。
- `pointer-events: none` を基本にし、ボタンだけ `pointer-events: auto`。空状態を無視してそのまま描き始められること。
- 見出しは置かず、3 つのアクションボタンを横並び（狭いときは縦）で:
  1. **線を描く** → `tool="line"` に切替（矢印は付けない。矢頭はインスペクタの「矢印」で足す）
  2. **数式を置く** → `tool="node"`
  3. **関数を描く** → `tool="plot"`
  各ボタンは小さな SVG 図（線 / `x²` / 放物線と軸）+ 日本語ラベル。
- 直下に説明 1 行（薄色・小さめ）: `作成した図は編集可能な TikZ コード、または PNG として挿入できます`
- ライブプレビュー画像が出ている間も、オブジェクトが 0 なら表示してよい（0 個なら絵も空なので邪魔にならない）。

### B1. 矢印プリセット（2026-08-15 撤去）

当初は「矢印を描く」ボタンが次の直線に `arrowEnd="Stealth"` を仕込む `pendingLineArrow` を持っていたが、
ラベルと実際の道具（直線ツール）がズレていたため、ボタンを「線を描く」に直してプリセットごと削除した。

## C. 文脈ヒントバー（常設・1 行）

`.pro-canvas-stage` の下端に `.pro-canvas-hintbar`（`pointer-events:none`、低コントラスト、1 行、はみ出しは省略）。**いま出来る操作だけ**を出す（全ショートカットを流さない）。

`render()` の最後に現在の tool と選択内容から決める:

- 選択なし・tool=select: `ドラッグで範囲選択　Space+ドラッグで画面移動　図形をダブルクリックで編集`
- tool=line: `ドラッグで直線　Shift で水平・垂直・45°`
- tool=rect / ellipse: `ドラッグで作成　Shift で正方形（正円）`
- tool=pen: `クリックで頂点追加　ドラッグで曲線　Enter で確定　Esc で取り消し`
- tool=node: `クリックした位置に数式ラベルを置きます`
- tool=plot: `クリックまたはドラッグでグラフを配置`
- tool=code: `クリックした位置に TikZ コードを直接書けます`
- plot を選択中: `ダブルクリック：グラフを編集　ホイール：軸を拡大　ドラッグ：軸を移動`
- node を選択中: `ダブルクリックで数式を編集`
- path を選択中: `ダブルクリックで頂点編集　端の□をドラッグで伸縮`
- 複数選択中: `Cmd+G でグループ化　矢印キーで微調整　Delete で削除`
- グラフ編集カードが開いている間: `式の入力中に / で分数　Esc で編集を終了`

## D. 対象上の初回ヒント（1 回だけ）

ヒントバーだけでは見ない可能性があるため、**副作用の大きいジェスチャ**にだけ、対象の近くに小さな吹き出しを 1 回出す。

- plot を初めて選択したとき: プロット矩形のすぐ上に `ダブルクリックして式を編集` 。
- node を初めて選択したとき: `ダブルクリックで数式を編集`。
- 実行された（＝実際にダブルクリックで編集に入った）ら即座に消し、以後出さない。何もしなくても **6 秒でフェードアウト**。
- 「1 回だけ」の記憶は `localStorage`（`tex64.proCanvas.hints.v1` に `{plotEdit:true,nodeEdit:true}`）。読み書きは try/catch。
- 実装は DOM のオーバーレイ要素（`.pro-canvas-coach`）で、`pointer-events:none`。SVG 内には描かない。

## E. コンパイル状態の言い方（キャンバスを覆わない）

現状のチップは残しつつ文言を整理する。既に `compileNow` に 4 秒後の切替タイマー（`slowNotice`）がある。

- 4 秒しきい値を **3 秒**にする。
- 初回（`compiledImage` が無い）: `TeX プレビューを準備中… 初回は 10〜15 秒かかります`
- 2 回目以降（`compiledImage` あり）: `TeX プレビューを更新中…`
- 完了時は従来どおり無言（空文字）に戻す。
- ★ 進捗率やカウントダウンは出さない。キャンバスを覆う要素も足さない（チップのまま）。

## F. 文言の整理

- `TikZ を挿入` → `TikZ コードを挿入`
- `画像として挿入 (PNG)` → `PNG 画像として挿入`
- `Live` トグル → ラベル `TeX プレビュー`（tooltip は既存の説明文を維持）
- `Doc` トグル → ラベル `プリアンブル`（tooltip は既存の説明文を維持）
- 上記トグルは色だけでなく **`aria-pressed` とチェック様の表現**でオン/オフが分かるようにする（既に `is-active` があるので、CSS でオン時に小さなチェック `✓` を疑似要素で出す等）。
- インスペクタ空文言 `オブジェクトを選択すると設定が表示されます` はそのまま。

（`✎ 作図` ボタン・`吸着 オン/オフ` は本タスク前に適用済み。触らない。）

F → A → E → C → B → D。各段で tsc を通す。D が最も壊れやすいので最後。
