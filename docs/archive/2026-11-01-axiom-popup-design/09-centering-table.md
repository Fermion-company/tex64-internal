# 文字の中央揃え 実測一覧（device px、Retina 2 倍。1 device px = 0.5 CSS px）

- 各セルは `縦 / 横`。**縦 = 上余白 − 下余白**（＋は文字が下寄り、− は上寄り）。**横 = 左余白 − 右余白**（＋は文字が右寄り、− は左寄り）。
- 余白は要素の枠の内側からインク（文字・アイコンの描画画素）までの距離。縦は g / p / y のディセンダを除くため、欧文は一時的に大文字化して測定（和文はそのまま）。
- `icon ±n` はアイコンの垂直中心 − 文字の垂直中心（＋はアイコンが下）。
- before = 91f417e（中央揃え着手前）、after = 現 HEAD。測定: Playwright 要素スクショ → ImageMagick trim。
