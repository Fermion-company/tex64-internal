## A. 設定・アカウント・利用量

1. **Axiom の設定ページ（利用者の好みだけ）**（M）。設定に AI の項目がゼロ。ただし
   `electron/services/user-settings.cjs` の `agent.*` は `model` だけになった（5 で整理済み）。
   ページに置くのは好みの項目だけ:
   - 既定モデル（入力欄のモデル選択と同じ値を設定からも変えられる）
   - 返答の言語（文書の言語に合わせる／日本語／英語）
   - 書き方の指示（文体・記法・引用形式の自由記述。毎ターン system に添える。37 の Rules の最小形。
     run-loop は `context.userInstructions` を受け取る口を持つ）
   - 送信キー（Enter / ⌘Enter）
